# BlinGenerator

A simple Python app that generates random Russian blini recipes.

## Demo

Watch BlinGenerator in action:



https://github.com/user-attachments/assets/7be60eb9-11ba-40b2-8723-ffb989e8a7e9



## Features

- Random blini recipes
- Different ingredients and toppings
- Cooking time and difficulty
- Recipe ratings
- Random blini facts

## Requirements

- Python 3
- Tkinter

## Run

Clone the repository:

```bash
git clone https://github.com/kotenok2013/blinigenerator.git
cd BlinGenerator
```

Run the application:

```bash
python3 blingenerator.py
```
